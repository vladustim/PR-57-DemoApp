# DemoApp

Консольний застосунок .NET для практичної роботи №57 «Супровід програм».

Запуск із кореня репозиторію після створення проєкту:

```powershell
dotnet run --project DemoApp
```

Розробка ведеться у гілці `dev`. Стабільні версії потрапляють у `master` через Pull Request. Гілка `release/1.1` використовується для підготовки версії 1.1.
